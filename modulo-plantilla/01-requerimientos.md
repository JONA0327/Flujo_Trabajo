# Requerimientos del módulo [Mxx]: [Nombre]

## Reglas para escribir un requerimiento
- Uno por fila, una sola idea. Si lleva "y", probablemente son dos.
- Debe ser **verificable**: si no se puede probar, se reescribe. Evita "rápido", "fácil", "amigable", "etc.".
- Todo requerimiento tiene criterio de aceptación en formato Dado / Cuando / Entonces.
- Un requerimiento aprobado no se edita: se cambia con solicitud de cambio.
